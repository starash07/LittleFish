# LittleFish 项目总览

更新时间：2026-05-25  
当前版本：1.5.2  
项目类型：C# / WPF / .NET 8 Windows 桌面应用

本文档用于后续继续开发时快速接上上下文，记录 LittleFish 已完成的功能、重要设计取舍、已踩过的问题和打包方式。

## 项目定位

LittleFish 是一个轻量级 TXT 阅读器，目标是低打扰、快速打开、适合在桌面角落阅读。它不是 TXT 编辑器，正文区域只用于阅读，不提供输入、修改、保存原文等编辑能力。

软件最初从 Python/Tkinter 原型迁移到 C# WPF。后续主要围绕阅读体验、窗口隐藏、透明背景、快捷键、设置界面、安装更新和主界面视觉风格持续迭代。

## 项目结构

- `LittleFish.sln`：解决方案。
- `src/LittleFish.App`：主程序 WPF 项目。
- `src/LittleFish.App/MainWindow.xaml`：主阅读窗口 UI。
- `src/LittleFish.App/MainWindow.xaml.cs`：阅读、快捷键、窗口行为、托盘、分页等核心逻辑。
- `src/LittleFish.App/SettingsWindow.xaml`：设置窗口 UI。
- `src/LittleFish.App/SettingsWindow.xaml.cs`：设置保存、快捷键修改、输入校验等逻辑。
- `src/LittleFish.App/ChapterPickerWindow.cs`：章节弹窗。
- `src/LittleFish.Installer`：自定义 WPF 安装器项目。
- `src/LittleFish.Installer/Assets/sponsor.png`：安装器赞助图。
- `scripts/build-installer.ps1`：发布、基础保护、封包脚本。
- `dist/setup`：最终安装包输出目录。

## 当前常用命令

```powershell
dotnet build LittleFish.sln
dotnet run --project .\src\LittleFish.App\LittleFish.App.csproj
powershell -ExecutionPolicy Bypass -File .\scripts\build-installer.ps1 -Version 1.5.2
```

封包脚本会发布主程序、执行 Obfuscar 基础保护、做一次启动烟测、生成 `LittleFish_Setup_v版本号.exe`。

## 核心阅读功能

- 打开本地 TXT 文件。
- 支持将 TXT 文件拖入窗口后直接打开。
- 支持“打开上次文件”。
- 支持最近打开文件记录。
- 正文只读，不允许输入、删除、粘贴修改原文。
- 支持基本编码识别，包含 UTF-8、UTF-8 BOM、GB18030、Big5 和系统默认编码兜底。
- 支持阅读进度显示。
- 支持菜单中的进度跳转，使用进度条加数字输入。
- 支持 Home 回到开头。
- 支持 End 跳到末尾。
- 支持 PageUp / PageDown 翻页。
- 支持键盘 ↑ / ↓ 翻动。
- 支持鼠标滚轮翻动。
- 支持恢复上次阅读位置。
- 阅读位置已改为基于字符位置记录，避免窗口大小变化或重启后因百分比定位导致跳章。
- 窗口大小变化后，会尽量保持改变前窗口第一行继续显示，避免重排后阅读位置跳动。

## 翻页与性能优化

- 默认翻动模式严格按一行翻动。
- 设置中可开启整页翻页。
- 开启整页翻页后，滚轮、自动翻页、↑ / ↓ 等翻动行为会按整页处理。
- PageUp / PageDown 始终用于整页向上 / 向下。
- 支持自动翻页。
- 自动翻页可通过功能栏“自动”按钮开启或暂停。
- 设置中可调整自动翻页间隔，单位为秒。
- 长文本拖拽缩放时曾出现严重卡顿，后来改为减少实时重排，并进一步采用按当前可见页渲染的方案，降低长文本窗口缩放和翻页压力。

## 查找、章节和书签

### 查找

- 查找入口收进“菜单”。
- 点击查找后弹出浮窗，不占用功能栏空间。
- 支持查找关键字和查找下一个。

### 章节

- 支持自动识别常见章节标题。
- 章节入口在顶部功能栏。
- 章节列表最初使用浮窗，因滚轮事件会穿透到正文，后改为独立章节弹窗。
- 点击章节后关闭弹窗并跳转。
- 章节跳转修正为尽量让章节标题显示在当前阅读区域第一行。
- 章节弹窗滚动条和关闭按钮已按当前浅蓝白风格重新设计。

### 书签

- 支持添加当前阅读位置为书签。
- 支持书签列表。
- 支持点击书签跳转。
- 支持删除书签。
- 书签浮窗已重新设计：列表区域放在独立框中，添加和删除按钮放在下方并对齐。

## 外观和透明度

当前采用三层思路：

1. 文字层：文字始终 100% 不透明。
2. 背景层：文字后方单独一层可自定义颜色的背景层。
3. 窗口层：整个窗口整体透明度。

已完成能力：

- 自定义文字颜色。
- 自定义背景颜色。
- 背景不透明度可调，范围最低 1%，最高 100%。
- 背景不透明度只影响背景层，不改变背景颜色，也不影响文字不透明度。
- 整窗不透明度可调，范围最低 1%，最高 100%。
- 悬隐不透明度可调。
- 字体可设置。
- 字号可设置。
- 字号设置已从滑条改为加减按钮加当前数值，并支持手动输入。
- 背景不透明度、整窗不透明度、悬隐不透明度在设置中显示明确数值，并支持手动输入。
- 设置里的颜色显示已从颜色编码改为颜色块。
- 设置界面滚动条、滑条、按钮都做过浅蓝白风格优化。

## 主窗口和功能栏

- 默认不显示系统标题栏和系统边框，使用自定义顶部功能栏。
- 默认不置顶，用户可自行开启。
- 顶部功能栏可作为拖拽区域移动窗口。
- 隐藏功能栏后，拖动正文区域可移动窗口。
- 隐藏功能栏后，拖动窗口边缘仍可调整窗口大小。
- 隐藏功能栏时，底部空白和边框跟随隐藏，正文区域不额外挤占或重排出功能栏空间。
- 窗口右下角传统缩放点取消，改为按窗口边缘缩放。
- 长文本滚动条隐藏，阅读进度显示在顶部状态区域。
- 外层保留浅蓝色细边，隐藏功能栏时跟随隐藏。
- 主窗口默认尺寸当前为 `960 x 522`。

### 1.5 主界面视觉方向

1.5 版本主要调整顶部功能栏视觉：

- 顶部导航仍保留在顶部，不采用左侧菜单。
- 不使用 Windows 上容易显得奇怪的半透明玻璃效果。
- 保留最外层浅蓝边框。
- 去掉内部多余蓝色描边和明显分割线。
- 功能入口整合成一个圆角胶囊式功能栏。
- 功能按钮改为图标加小字。
- 默认图标和小字为浅灰色。
- 鼠标悬停时图标和小字一起变浅蓝色，不显示背景底色。
- 菜单、章节、书签、自动、帮助均使用矢量图标，避免字体图标在不同系统上变形。
- 进度和文件名状态区域改为无描边浅蓝色圆角胶囊，位置跟随左侧功能栏。
- 文件名显示区域加长。

## 菜单和帮助

顶部功能栏包含：

- 菜单。
- 章节。
- 书签。
- 自动。
- 帮助。
- 文件名 / 进度 / 自动状态。
- 最小化、最大化 / 还原、关闭。

菜单中包含：

- 打开 TXT。
- 打开上次文件。
- 查找。
- 进度跳转。
- 设置。

帮助使用浮窗形式，当前写入的主要功能包括：

- F6 开启或关闭自动翻页。
- F7 隐藏功能栏。
- Ctrl+T 开启 / 关闭置顶模式。
- F9 开启鼠标移出隐藏 / 进入显示。
- 设置中可开启整页翻页和调整自动翻页间隔。
- 设置中可自定义文字颜色、背景颜色和文字大小。
- Ctrl + 鼠标滚轮调整背景不透明度。
- Alt + 鼠标滚轮调整整窗不透明度。
- 菜单中可进行进度跳转。
- Ctrl+Shift+Z 触发老板键 / 快捷隐藏。
- Ctrl+Shift+F12 找不到窗口时强制显示窗口。
- Ctrl+W 关闭软件。
- 设置中可开启最小化到托盘。
- 所有可修改快捷键可在设置中修改。

## 窗口隐藏、置顶、托盘和恢复

- 支持窗口置顶开关。
- 支持鼠标移出后悬隐，鼠标进入后显示。
- 支持功能栏隐藏 / 显示。
- 支持老板键 / 快捷隐藏：默认 `Ctrl+Shift+Z`。
- 老板键隐藏后可再次按快捷键恢复。
- 支持最小化到托盘。
- 开启最小化到托盘后，窗口激活状态也不在任务栏显示，避免违背托盘隐藏的目的。
- 托盘菜单支持显示 / 隐藏和退出。
- 支持强制显示窗口：固定快捷键 `Ctrl+Shift+F12`，不可修改。
- 强制显示会将窗口调至最前，背景不透明度恢复 100%，整窗不透明度恢复 100%，并取消功能栏隐藏。
- 设置 > 窗口 中有强制显示功能说明，使用点击问号弹出说明。

## 快捷键

所有主要功能快捷键支持在设置中修改，修改方式为点击“修改”后直接按下目标按键组合。支持清空某个快捷键，清空后该功能不再响应对应快捷键。

默认快捷键：

- `Ctrl+O`：打开 TXT。
- `Ctrl+,`：打开设置。
- `Ctrl+F`：查找。
- `F3`：查找下一个。
- `Ctrl+B`：添加书签。
- `F8`：打开章节弹窗。
- `F7`：显示 / 隐藏功能栏。
- `Ctrl+T`：开启 / 关闭置顶。
- `F9`：开启 / 关闭悬隐。
- `F6`：开启 / 关闭自动翻页。
- `Ctrl+Shift+Z`：老板键 / 快捷隐藏。
- `↑`：向上翻动。
- `↓`：向下翻动。
- `Ctrl+Plus`：增大字号。
- `Ctrl+Minus`：减小字号。

固定快捷键：

- `Ctrl+Shift+F12`：强制显示窗口，不支持修改。
- `Ctrl+W`：关闭软件，不放入设置，不支持修改。
- `Home`：回到开头。
- `End`：跳到末尾。
- `PageUp`：上一页。
- `PageDown`：下一页。
- `Ctrl + 鼠标滚轮`：调整背景不透明度。
- `Alt + 鼠标滚轮`：调整整窗不透明度。

快捷键显示已避免使用 `Control` 这种全称，统一使用 `Ctrl`、`Alt`、`Shift`、`↑`、`↓` 等更易理解的写法。

## 设置窗口

设置窗口已从系统默认窗口改为自定义 UI 风格：

- 无系统标题栏和系统边框。
- 使用自定义圆角窗口。
- 支持拖动窗口。
- 标签页统一为浅蓝白风格。
- 修复过标签页重叠、按钮状态颜色看不清、滚动条太丑、保存按钮状态错误等问题。
- 设置项分为外观、窗口、翻页、快捷键。
- 点击保存后自动应用并关闭设置窗口。
- 点击应用只应用不关闭。
- 修改快捷键不会即时保存，只有保存或应用后才生效。
- 快捷键区域删除了早期多余说明卡片。

## 安装器、封包和更新

当前安装器为自定义 WPF 安装器，不使用传统默认安装向导 UI。

已完成能力：

- 单文件安装包。
- 安装时允许选择安装位置。
- 用户选择任意路径时，实际安装目录都会自动追加 `LittleFish` 文件夹。
- 如果用户选择的路径已经是 `LittleFish` 文件夹，则不会重复追加。
- 支持创建桌面快捷方式。
- 支持创建开始菜单快捷方式。
- 开始菜单包含启动和卸载快捷方式。
- 支持安装完成后启动 LittleFish，选项放在安装完成页。
- 安装界面包含赞助图 `sponsor.png`。
- 安装器使用当前 LittleFish 图标。
- 卸载界面改为简洁小窗口。
- 卸载不依赖 PowerShell，避免杀毒软件误报倾向。
- 卸载时会清理桌面快捷方式、开始菜单目录和注册表卸载项。
- 卸载器从安装目录中自复制到临时目录再执行，避免正在运行的卸载器删不掉自己。
- 更新安装时会读取注册表中的已安装路径和版本。
- 检测到已安装版本时，会进入覆盖更新逻辑，而不是让用户装出多个版本。
- 更新时会尽量关闭正在运行的 LittleFish 进程。
- 更新失败信息已改成更明确的文件占用提示。
- 更新会根据安装清单清理旧版本冗余文件，避免旧文件长期留在安装目录。

打包流程：

- `scripts/build-installer.ps1` 发布主程序到 `dist/installer/publish`。
- 复制到 `dist/installer/protected`。
- 使用 Obfuscar 对 `LittleFish.dll` 做基础保护。
- 对保护后的程序做启动烟测。
- 压缩 protected 目录为安装器 payload。
- 发布安装器为单文件。
- 最终复制到 `dist/setup/LittleFish_Setup_v版本号.exe`。
- 临时 `payload.zip` 会在打包后删除。

最近一次已生成：

- `dist/setup/LittleFish_Setup_v1.5.2.exe`

## 加密和保护说明

当前选择的是基础保护方案：

- 使用 Obfuscar 处理主程序 DLL。
- 启用私有 API 隐藏、字符串隐藏、名称复用、SuppressIldasm。
- 这不是绝对防逆向保护，不能保证“不会被反向解密”。
- 目标是提高普通反编译和直接阅读源码逻辑的门槛。

如果后续要加强保护，需要另行评估商业混淆器、授权校验、签名、完整性校验和自动更新渠道。

## 已解决的重要问题

- 背景不透明度最初直接影响窗口或改变颜色，已改为独立背景层。
- 背景透明到 0 后无法调回，已通过最低 1% 和独立背景层逻辑规避。
- 打开 TXT 后点击正文出现异常置顶窗口，后续 UI 和弹窗逻辑已重做。
- 文字出现绿色描边，已修复。
- 功能栏隐藏后无法拖动和缩放，已修复。
- 功能栏隐藏后正文区域被挤占或底边空白仍存在，已多轮调整。
- 长文本拖拽窗口大小卡顿，已通过减少重排和当前页渲染优化。
- 章节跳转位置不准，已改用原始文本字符位置并修正定位。
- 章节浮窗滚轮无法滚动，已改为独立弹窗。
- 书签缺少删除能力，已补上。
- 快捷键录入无法录入组合键，已修复。
- 快捷键修改即时保存，已改为保存 / 应用后生效。
- 设置 UI 重叠、默认标题栏、滚动条样式不统一等问题已多轮优化。
- 老板键和托盘隐藏补齐。
- 已安装用户更新时可能装出两个版本，已改为读取注册表并覆盖更新。
- 用户自定义安装目录导致更新路径不同，已改为统一追加 `LittleFish` 子目录。
- 阅读进度曾按百分比保存，窗口大小变化后容易跳章，已改为字符位置定位。

## 当前设计取舍

- 不做 TXT 编辑能力，保持只读。
- 不做左侧导航栏，顶部功能栏更符合当前小工具定位。
- 不使用半透明玻璃效果，避免 Windows 上显示不稳定或廉价感。
- 保留浅蓝色外边框，用于白色桌面背景下识别窗口边界。
- 隐藏功能栏时仍要保证窗口可拖动、可缩放。
- 默认不置顶，避免第一次打开就压住其他窗口。
- 背景不透明度最低 1%，避免用户完全透明后找不到窗口。
- 强制显示快捷键固定不可修改，用作兜底救援。

## 后续开发注意点

- 不要把 `bin`、`obj`、`dist/installer` 等构建产物当作源码维护。
- 打包前用 `dotnet build LittleFish.sln` 验证。
- 打包用 `scripts/build-installer.ps1 -Version x.y.z`，注意同步安装器界面版本显示。
- 改动阅读位置、分页、窗口缩放逻辑时，要重点测试长文本、窗口极小尺寸、重启后恢复位置。
- 改动透明度相关逻辑时，要分别测试背景层透明度和整窗透明度，确认文字不受背景透明度影响。
- 改动隐藏功能栏逻辑时，要测试隐藏状态下拖动窗口、边缘缩放、强制显示和老板键恢复。
- 改动安装器时，要测试全新安装、覆盖更新、卸载、安装到磁盘根目录、安装到已有 LittleFish 目录这几种场景。
